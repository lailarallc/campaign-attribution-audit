# campaign-attribution-audit

Every marketing report asserts a ROAS. The number rests on an attribution rule picked from a dropdown and on tracking data full of silent defects. This tool scores the same spend and conversions under the standard attribution rules and audits the tracking defects that decide how much of the data can be attributed at all. Status: scoping (`/clarify`); public tool name not yet chosen.
